# 🧾 Kaggle Survey Data Analysis & Cleaning

🎯 Project Purpose
Analyze and clean the Kaggle survey dataset to prepare it for further machine learning and visualization tasks.
The project focuses on handling missing values, encoding categorical data, detecting and handling outliers, and generating summary insights about participants’ education levels, countries, and job roles.

⚙️ Setup / Installation
1- Download or clone this repository:
git clone https://github.com/yourusername/Kaggle-Survey-Data-Cleaning.git
2- Open the Jupyter Notebook: notebooks/Kaggle_Survey_Cleaning.ipynb
3- Run the notebook step-by-step to reproduce the cleaning and EDA process.
All cleaned data will be saved automatically to: data/cleaned_kaggle_survey.csv

💡 Usage / Results
- Clean raw Kaggle survey data by removing duplicates and handling missing values.
- Encode all categorical columns for ML readiness.
- Check and analyze outliers using IQR (removed step due to excessive loss).

🧰 Technologies Used
- Python: Data processing and analysis
- Pandas, NumPy: Data cleaning & manipulation
- Matplotlib, Seaborn: Data visualization
- Scikit-learn: Label encoding and preprocessing
- Jupyter Notebook: Workflow documentation
